# References

This folder holds context material for agents and humans: domain rules, real-world samples, and condensed library notes. Files here describe **the world**. Rules for **our code** live in [`../standards/`](../standards/).

| Path | What |
|---|---|
| [bingo-rules-us-75.md](bingo-rules-us-75.md) | Card layout, ranges, validation, and win patterns. The source of truth for the domain. |
| [bingo-cards/](bingo-cards/README.md) | Real card photos and PDFs with ground truth. They are also test fixtures. |
| [ui/](ui/) | Wireframes, screenshots, and visual references for target screens. Name files `<feature>-<screen>.png`. |

Condensed library notes (`skie.md`, `room-kmp.md`, `koin.md`, …) are added here when a library joins the project. Each one is a single page: which version we use, how we use it, and the gotchas that agents tend to get wrong.
